============================================================
              PANDUAN PENGGUNAAN ARX GITHUB
============================================================

1. SYARAT AWAL:
   - Install Python 3.11 / 3.12 / 3.13 / 3.14 (Download di: https://www.python.org/downloads/)
   - PENTING: Saat install Python di Windows, WAJIB CENTANG opsi:
     [v] "Add python.exe to PATH"

2. CARA INSTALL (Hanya Sekali di Awal):
   - Klik 2x file: 'install.bat'
   - Tunggu sampai muncul pesan "INSTALASI BERHASIL".

3. SETTING EMAIL GMAIL (Di file config.json):
   - Buka file 'config.json' pakai Notepad / Text Editor.
   - Ubah:
     "gmail_address": "emailmu@gmail.com"
     "gmail_app_password": "xxxx xxxx xxxx xxxx"
   - Catatan: gmail_app_password BUKAN password login Gmail biasa!
     Cara buat App Password Gmail:
     1. Aktifkan 2FA di Akun Google (Security -> 2-Step Verification)
     2. Buka https://myaccount.google.com/apppasswords
     3. Bikin App Password baru (beri nama bebas misal: arx)
     4. Salin 16 digit kode password yang dikasih ke config.json.

4. SETTING PROXY (Di file proxies.txt):
   - Buka file 'proxies.txt' pakai Notepad.
   - Tempel proxy kamu (1 proxy per baris).
   - Format didukung:
     host:port:user:pass
     user:pass:host:port
     http://user:pass@host:port
     socks5://user:pass@host:port

5. CARA MENJALANKAN:
   - OPSI A (Mode CLI / Terminal):
     Klik 2x 'farm.bat' -> Masukkan jumlah akun -> Enter.
   - OPSI B (Mode Web Console):
     Klik 2x 'console.bat' -> Otomatis buka browser di http://127.0.0.1:8093

6. LOKASI HASIL AKUN:
   - Akun yang berhasil akan tersimpan di folder 'accounts/'.
   - Format: email----password----username
   - Recovery code ada di 'accounts/recovery/'.
============================================================
